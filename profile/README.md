# Blax Software

We build web platforms, SaaS products and real-time apps with **Laravel**, **Nuxt** and **WebSockets**, from Gallneukirchen near Linz, Austria.

We build these packages for our own projects. [LearnATC](https://www.learn-atc.com), for example, runs on laravel-websockets, laravel-shop, laravel-roles, laravel-files and laravel-workkit.

## Packages

| Package | What it does |
|---|---|
| [laravel-websockets](https://github.com/blax-software/laravel-websockets) | WebSockets for Laravel, maintained: controllers, channels, broadcasting and progress streaming |
| [laravel-ws](https://github.com/blax-software/laravel-ws) | Next-gen WebSocket server for Laravel on the blax ReactPHP kernel |
| [reactphp-kernel](https://github.com/blax-software/reactphp-kernel) | Event loop, socket accept, IPC and graceful shutdown shared by our real-time servers |
| [laravel-shop](https://github.com/blax-software/laravel-shop) | Headless e-commerce for Laravel with stock management and Stripe |
| [laravel-roles](https://github.com/blax-software/laravel-roles) | Roles and permissions, including roles with expiry dates |
| [laravel-files](https://github.com/blax-software/laravel-files) | Upload, optimize, serve and attach files to any model |
| [laravel-addresses](https://github.com/blax-software/laravel-addresses) | Address management from rural coordinates to single rooms |
| [laravel-invoicing](https://github.com/blax-software/laravel-invoicing) | Invoices with gapless numbering, VAT or Austrian small-business mode |
| [laravel-mail](https://github.com/blax-software/laravel-mail) | Per-mailbox SMTP and IMAP, threading and tracking |
| [laravel-workkit](https://github.com/blax-software/laravel-workkit) | Helpers we reuse across every Laravel project |
| [docker-laravel](https://github.com/blax-software/docker-laravel) | PHP + Nginx Docker images for Laravel, PHP 8.0 to 8.4 |
| [npm-networking](https://github.com/blax-software/npm-networking) | `api.` and `ws.` helpers for Vue and Nuxt clients |
| [npm-i18n](https://github.com/blax-software/npm-i18n) | Per-page translation sources for vue-i18n and Nuxt |
| [wordpress-plugin-framework](https://github.com/blax-software/wordpress-plugin-framework) | Structure and features for WordPress plugin development |
